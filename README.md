# Movie Recommendation Engine

A simple content-based movie recommendation system built using Python.  
It suggests movies similar to a user’s favorite movie based on features like keywords, genres, cast, and director.

## Project Description

This project uses **machine learning (content-based filtering)** to recommend movies.  
It analyzes movie metadata and finds similarities using cosine similarity.
